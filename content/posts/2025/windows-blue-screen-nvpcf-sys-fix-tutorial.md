## 问题描述

在对电脑进行清灰维护后，第一次开机一切正常，所有功能运行正常。然而第二次启动时，系统出现了无法启动：

![蓝屏错误界面](https://img.shenley.top/blog/2025/windows-blue-screen-nvpcf-sys-fix-tutorial/IMG_20251107_220107.jpg)

系统提示"自动修复，您的电脑未正常启动"，并在蓝屏瞬间闪过 `nvpcf.sys` 字样（Windows 11 25H2 版本则显示为黑屏）。

## 问题排查

- 尝试 UEFI 诊断 - 未解决
- 尝试系统自动修复 - 未解决  
- 关键线索：错误信息中出现 `nvpcf.sys`，`nv` 开头通常指向 NVIDIA（英伟达）相关文件

由此判断，问题可能出在显卡驱动上。

## 解决方案

### 步骤 1：进入安全模式

1. 在修复界面选择「高级选项」
2. 找到并点击「命令提示符」
3. 在命令提示符中输入以下命令：

```bash
bcdedit /set {default} safeboot minimal
```

4. 重启电脑，此时应该可以进入安全模式

### 步骤 2：卸载 NVIDIA 驱动

1. 成功进入安全模式后，打开「设置」→「应用」→「已安装的应用」
2. 找到 NVIDIA 相关驱动程序并完全卸载

### 步骤 3：恢复正常启动模式

**重要提示**：在退出安全模式之前，需要先恢复正常启动配置。

1. 按 `Win + R` 打开运行对话框
2. 输入 `cmd` 并回车（注意：必须是 CMD，不能用 PowerShell）
3. 在命令提示符中输入：

```bash
bcdedit /deletevalue {default} safeboot
```

4. 再次重启电脑

### 步骤 4：重新安装驱动

系统成功进入后，前往 [NVIDIA 官网](https://www.nvidia.cn/Download/index.aspx?lang=cn)下载并安装最新版本的显卡驱动。

## 总结

该问题通常由显卡驱动与系统不兼容或驱动损坏引起。通过安全模式卸载旧驱动，然后重新安装最新驱动即可解决。如果你在清灰或硬件维护后遇到类似问题，不妨试试这个方法。

**注意事项**：
- 务必按顺序执行命令，避免系统一直处于安全模式
- 卸载驱动前确保已设置为安全模式，否则可能无法进入系统
- 重新安装驱动时建议下载官方最新版本
